## Geometric Characterization of Embedding Spaces Across Chunking Strategies and Embedding Models for Slovenian Text

Authors: Anja Jodl, Mitko Nikov

This repository contains the code and data from the paper "Geometric Characterization of Embedding Spaces Across Chunking Strategies and Embedding Models for Slovenian". The study investigates how different chunking strategies and embedding models affect the geometric properties of embedding spaces for the Slovenian language.

### Code

The code is based on the [semora](https://github.com/GeMMA-FERI/semora) python package,
which is developed by the authors of the paper, as an extensible tool for
semantic processing, analysis and retrieval of text.

The [./scripts/main.sh](./scripts/main.sh) script is the main entry point that does everything from
processing the newspapers in the [./data/newspapers](./data/newspapers) directory, to generating the embeddings.

---

### Data

The data is stored in the [./data](./data) directory. It includes the statistical data and results
from the experiments conducted in the study. Unfortunately, we cannot provide all of the original
Slovenian newspapers due to copyright restrictions, however, we provided couple of samples
of the newspaper markdown files in the [./samples/newspapers](./samples/newspapers) directory.
